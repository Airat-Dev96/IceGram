# icegram

Независимая модификация **exteraGram 13.2.2** с акцентом на экономию ресурсов.
Это не официальный Telegram и не выпуск команды exteraGram.

Основа: <https://github.com/exteraSquad/exteraGram>, коммит
`b4d852f48f2734a0bee1a74a0939be621612262a` от 24 ноября 2026 года.
Оригинальные авторские уведомления сохранены.

Репозиторий модификации: <https://github.com/Airat-Dev96/IceGram>.
При распространении APK указывайте также точный коммит, из которого он собран.

## Что изменено

- Отдельное имя **icegram**, пакет `org.icegram.messenger` и собственный
  векторный значок. Устанавливается отдельно от exteraGram.
- Целевая сборка — **full**: движок плагинов exteraGram, встроенный Python
  и method hooking сохранены. Вариант lite остаётся в исходниках upstream,
  но не используется в сценарии выпуска icegram. Full крупнее lite;
  установленные плагины могут дополнительно расходовать память и батарею.
- Встроенные карты и выбор места на карте отключены, Google Maps SDK
  исключён. Картографические миниатюры также не запрашиваются.
  Google Location и разрешения геолокации сохранены; это не полное удаление
  всей геолокационной функциональности. Ключ Google Maps не нужен.
- По умолчанию выключены дополнительные анимации, размытие, частицы,
  автопроигрывание GIF и видео. Есть кнопка повторного применения **Ice Mode**
  и переход к штатным детальным настройкам энергосбережения.
- Компактные кэши изображений: до **16 МиБ** для изображений и миниатюр вместе,
  до **2 МиБ** для обоев и **2 МиБ** для анимаций. На слабых устройствах — меньше.
  Это лимиты повторно используемых кэшей, **не всей памяти приложения**.
  Можно вернуть исходные лимиты переключателем и перезапуском.
- При запуске не прогревается отдельный HTML-движок виджетов. Движок
  доступен при открытии виджета; прогрев можно вернуть в настройках.
- Экран «icegram · Лёгкость и удобство»: компактный кэш, виджеты,
  скрытие своего номера в интерфейсе и существующая кнопка сохранения
  сообщения в «Избранное», переход к плагинам. Это быстрые настройки возможностей upstream,
  а не новые серверные функции Telegram.
- Более спокойные начальные настройки: без пружинных переходов и
  анимации деформации аватаров; отправка фото не принудительно в HD.
  Пользовательские настройки не перезаписываются при каждом запуске.
- Сбор Google Analytics и Crashlytics выключен по умолчанию, в том числе
  до инициализации приложения. FCM для уведомлений не вырезается.
- Обновления из каналов exteraGram отключены: чужой APK не должен
  предлагаться как обновление icegram. Собственного сервера обновлений пока нет.
- Сохранены лицензия, авторство и ссылка «На основе exteraGram» в интерфейсе.

## Чего эта версия не обещает

Нельзя обещать «в два раза быстрее», определённый расход ОЗУ или размер APK
без сборки и измерений. Уменьшение кэша может увеличить повторное декодирование
и дисковую активность. Уведомления, звонки и соединения Telegram намеренно
не отключались ради красивых цифр. Запрет автозапуска видео **не равен**
запрету автозагрузки: она настраивается отдельно в разделе «Трафик».

Это первый исходный прототип. До распространения нужны полная Android-сборка
и проверка на устройстве. На телефоне доступен Linux с Git и Python для
подготовки публикации. JDK, Android SDK и NDK не установлены: APK и замеры
производительности не получены. Полная сборка выполняется через GitHub Actions.

## Где настройки

Настройки → Настройки icegram → **icegram · Лёгкость и удобство**.
Скрытие номера действует только на интерфейс на этом устройстве:
серверные настройки приватности Telegram от него не меняются.

## Подготовить Git-форк

Эта папка — снимок исходников с изменениями, **не созданный GitHub-форк**.
Скачанный архив GitHub не содержит `.git` и содержимого подмодулей.
Не загружайте его как новый независимый репозиторий с потерей истории.

На компьютере с Git запустите из корня проекта:

```sh
sh Tools/icegram/init-fork.sh
git status --short
```

Скрипт создаёт ветку `icegram` от закреплённого коммита, восстанавливает индекс
и gitlinks подмодулей, **не заменяя файлы рабочего дерева**, затем скачивает
зависимости. Если `.git` уже существует, скрипт останавливается без изменений.
Загрузка подмодулей может быть большой. Если она прервалась:

```sh
git submodule update --init --recursive --depth=1
```

На телефоне, используемом только для отправки исходников в CI, можно вместо
первой команды выполнить `ICEGRAM_METADATA_ONLY=1 sh Tools/icegram/init-fork.sh`.
Это сохраняет закреплённые ссылки подмодулей без скачивания их содержимого;
GitHub Actions загрузит его сам. Не удаляйте gitlinks при подготовке коммита.

Для публикации под своим аккаунтом войдите в GitHub CLI (`gh auth login`)
и создайте настоящий fork:

```sh
gh repo fork exteraSquad/exteraGram --fork-name icegram --clone=false
```

Добавьте свой репозиторий как `origin`, проверьте изменения, создайте коммит
и отправьте ветку `icegram`. Не включайте ключи и персональные файлы.
Пример, где `YOUR_NAME` нужно заменить своим GitHub-логином:

```sh
git remote add origin https://github.com/YOUR_NAME/icegram.git
git add .
git commit -m "Introduce icegram full profile without embedded maps"
git push -u origin icegram
gh repo edit YOUR_NAME/icegram --default-branch icegram
```

После публикации добавьте ссылку на **свои изменённые исходники** в README
и рядом с выпускаемым APK. Одна ссылка на upstream не заменяет обязанность
предоставить соответствующие исходники модификации по GPL.

## Сборка

Ориентируйтесь на актуальный `TMessagesProj/build.gradle`, а не на старый
upstream Dockerfile: у этого снимка `compileSdk` **37**, `targetSdk` 36,
Build Tools **36.0.0**, NDK **29.0.14206865**, CMake **4.x**, JDK **17**
и Python **3.11**. Android SDK/NDK рассчитаны на поддерживаемый компьютер
или CI; включение Linux на ARM-телефоне само по себе не обеспечивает их работу.

1. Инициализируйте подмодули командой выше.
2. Скопируйте `API_KEYS.example` в `API_KEYS`.
3. Получите **собственные** `APP_ID` и `APP_HASH` на
   <https://my.telegram.org/apps>. Не используйте чужие ключи.
   Ключ Google Maps не требуется: встроенные карты отключены.
4. Создайте Firebase Android-приложение с пакетом `org.icegram.messenger`,
   скачайте **свой** `google-services.json` и положите в `TMessagesProj/`.
   Конфигурация проекта exteraGram не используется. Для FCM, входа и других
   Google-сервисов настройте свой Firebase-проект и отпечатки сертификата.
5. Для release создайте `TMessagesProj/config/icegram.jks` через `keytool`
   и укажите пароли и alias в `API_KEYS`. Храните резервную копию ключа:
   без него невозможно подписывать совместимые обновления.
   Debug использует стандартный отладочный ключ и не подходит для релизов.

Python 3.11 нужен Chaquopy и сборке SDK плагинов. Движок также загружает
анализатор плагинов; требуется сеть. Если интерпретатор не называется
`python3.11`, задайте `BUILD_PYTHON` полным путём к Python **3.11**.

Сборка для современного ARM64-телефона на Linux/macOS с нужным toolchain:

```sh
export BUILD_PYTHON="$(command -v python3.11)"
sh gradlew :TMessagesProj:generateAppIcons \
  :TMessagesProj:assembleFullArm64Debug
sh gradlew :TMessagesProj:generateAppIcons \
  :TMessagesProj:assembleFullArm64Release
```

`generateAppIcons` удаляет старые сгенерированные значки upstream и создаёт
ресурсы, launcher alias и реестр icegram. Основной legacy vector хранится
в `src/main/res`, поэтому удаление generated-каталога его не затрагивает.

Для 32-битного ARM замените `Arm64` на `Armv7`. Одна архитектура обычно
даёт меньший APK, чем универсальный вариант. Для сравнения производительности
используйте **release**, не debug. R8 и shrinkResources уже включены upstream.

Результат: `TMessagesProj/build/outputs/apk/`.

## GitHub Actions

- **icegram checks** — JVM-тесты расчёта лимитов кэша и структурные проверки
  ресурсов, брендинга и настроек. Не заменяет компиляцию всего клиента.
- **Build icegram APK** — ручная сборка подписанного **full release** с
  плагинами, без встроенных карт, для ARM64/ARMv7. Настраивает Python 3.11
  и генерирует значок перед Android-сборкой.
  Нужно сначала опубликовать настоящий форк с подмодулями и настроить secrets:
  `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `GOOGLE_SERVICES_JSON_BASE64`,
  `ICEGRAM_KEYSTORE_BASE64`, `ICEGRAM_STORE_PASSWORD`,
  `ICEGRAM_KEY_PASSWORD`, `ICEGRAM_KEY_ALIAS`.
  Ключи добавляются в Settings → Secrets and variables → Actions репозитория,
  **не в переписку и не в исходники**.

Workflow не запускает сборку с секретами для pull request из чужих репозиториев.
В артефакт попадают APK, лицензии и ссылка на соответствующий коммит исходников.
Большой native-проект может потребовать больше диска/ОЗУ, чем доступно runner.

## Проверки

На машине с JDK 17 и Python 3.11:

```sh
sh Tools/icegram/test-policy.sh
python3 Tools/icegram/check-source.py
```

Перед релизом выполните ручной чек-лист из `Tools/icegram/TESTING.md`.
